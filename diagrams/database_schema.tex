\scriptsize
\textbf{\small Database Schema \& Reactive Engine Glossary}\\[0.3em]
\begin{tabular}{@{}p{0.31\linewidth}@{\hspace{0.035\linewidth}}p{0.31\linewidth}@{\hspace{0.035\linewidth}}p{0.31\linewidth}@{}}
\textbf{PrismDB}: Local client-side database built on IndexedDB storing sessions, habits, tasks, and settings securely in-browser. &
\textbf{PK (\texttt{++id} / \texttt{\&id})}: Primary Key; \texttt{++id} auto-increments integers; \texttt{\&id} designates unique string/UUID keys. &
\textbf{\texttt{useLiveQuery()}}: Reactive hook subscribing React components to live query results, auto-rerendering on data change.\\

\textbf{IndexedDB (IDB)}: W3C standard browser NoSQL object store providing high-capacity transactional persistence. &
\textbf{Idx / Compound Index}: Secondary B-tree index; \texttt{[a+b]} enables high-speed compound filtering without full scans. &
\textbf{FK (Foreign Key)}: Logical relational link associating child entity records with parent table primary keys ($1:N$).\\

\textbf{Dexie.js v3}: Minimalist TypeScript wrapper over IndexedDB handling migrations, indices, and transactions. &
\textbf{Multi-Entry (\texttt{*tags})}: Array index where each element is indexed individually for rapid membership search. &
\textbf{CRUD Transactions}: Atomic Create, Read, Update, and Delete operations executed with ACID guarantees in browser.
\end{tabular}
