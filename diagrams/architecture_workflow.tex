\scriptsize
\textbf{Glossary of Terms \& Abbreviations:}\\[0.25em]
\begin{tabular}{@{}p{0.48\linewidth}@{\hspace{0.03\linewidth}}p{0.48\linewidth}@{}}
$\bullet$ \textbf{FastAPI}: High-performance asynchronous Python web framework for backend APIs. & $\bullet$ \textbf{ReAct}: Reason + Act (agent loop alternating between reasoning and tool calls).\\
$\bullet$ \textbf{REST}: Representational State Transfer (standard HTTP API design pattern). & $\bullet$ \textbf{ORPO}: Odds Ratio Preference Optimization (direct model alignment without reward model).\\
$\bullet$ \textbf{SSE}: Server-Sent Events (persistent HTTP connection for real-time text streaming). & $\bullet$ \textbf{IndexedDB}: Transactional browser database for client-side persistence (\texttt{PrismDB}).\\
$\bullet$ \textbf{MCP}: Model Context Protocol (open standard for agent tool and resource discovery). & $\bullet$ \textbf{Dexie.js / \texttt{useLiveQuery}}: Reactive JavaScript engine updating UI on DB changes.\\
$\bullet$ \textbf{DAG}: Directed Acyclic Graph (execution plan with task dependency order, no cycles). & $\bullet$ \textbf{ROC-AUC / ECE}: Classification discrimination metric / Expected Calibration Error.
\end{tabular}
